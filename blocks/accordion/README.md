# accordion

Custom **accordion** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Content model

| Row | Cell 1 | Cell 2 |
|---|---|---|
| one per item | Question (summary) | Answer (one or more paragraphs) |

Each row becomes a native `<details>/<summary>` panel, closed by default.
