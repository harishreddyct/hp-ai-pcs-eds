# promo

Custom **promo** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |

## Universal Editor fields

N/A (Document Authoring project)

## Content model

| Row | Content |
|---|---|
| media | Image |
| content | Optional logo image, H2, paragraph(s), optional italic note, 1-2 CTA links |

Row order sets the image side: whichever row comes first renders on the left. Use `Promo (dark)` for the solid dark, edge-bleeding image, white-text treatment.
